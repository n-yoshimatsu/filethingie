# File Thingie PHP 8.3とPHP 8.5への移行計画

File Thingie 2.5.7のファイル管理機能をPHP 8.3とPHP 8.5で利用できるようにするための移行計画です。
既存の基本操作と設定をできるだけ維持し、互換性修正、認証・ファイル操作の見直し、機能検証を段階的に行います。

作成日：2026年10月24日（日本時間）

`master`は上流の履歴を保持し、変更は作業ブランチで管理します。ローカルでは`upstream`を上流、`origin`をフォーク先に割り当てます。

## 対応範囲

実運用先で利用できるPHP 8.3を対応対象に含め、指定されたPHP 8.5対応も維持する方針です。PHP 8.3で利用できる構文・APIを基準に実装し、8.3と8.5の両方で検証します。PHP 5.3から8.5までの変更を確認し、非互換構文・削除関数・型の扱い・非推奨処理を修正します。PHP 5系・7系・8.0〜8.2の互換性維持と、PHP 8.4の個別検証は初回の対応範囲案に含めません。

優先対象は、ログイン、ユーザー・グループ設定の読み込み、ファイル一覧、転送、作成、編集、名前変更、移動、複製、削除、検索です。日本語UIと日本語ファイル名も検証対象にします。

追加プラグインは使用しないため、同梱プラグイン10種類を調査対象とします。同梱プラグインの有効化状況は未確認のため、サンプル設定だけから実運用状態を判断しません。上流で未完成の機能や外部エディター連携は、互換性修正と機能追加の境界を明示します。機能を削除・置換する場合は影響と移行方法を示します。

認証情報の保存方式、ログインCookie、セッション、CSRF対策、HTML・JavaScriptへの出力、管理対象パスの制限、アップロード・ZIP処理を見直します。認証方式を変更する場合は既存設定からの移行と復元手順を用意します。

大規模な画面刷新、フレームワークへの全面移植、新規機能の追加は初回の対応範囲案に含めません。ソース内にある`SIMPLE`分岐だけを根拠に、単一ファイル版の配布を対応済みとは扱いません。取得したリポジトリは`EXPANDED`構成です。

公式仕様の参照先：[基本仕様](https://help.sakura.ad.jp/rs/2251/)、[PHPバージョン設定](https://help.sakura.ad.jp/rs/2241/)、[PHP提供ポリシー](https://help.sakura.ad.jp/rs/2256/)（2026年10月24日確認）。実機の動作モードと拡張構成は段階5の[受入記録](SAKURA_ACCEPTANCE.md)に反映済みです。サーバーのPHP設定変更や本番への配置は、段階1では実施していません。

共有サーバーへの配置は、アプリケーションファイルと設定の転送で完了する構成を基本とします。ZIP処理はPHPの標準拡張を優先候補とし、実サーバーの拡張有無を確認してから採用します。外部コマンドのパスやGNU固有の動作に依存しない設計を目指します。

日本語ファイル名はアプリケーション側の検証対象を維持します。公式基本仕様にはファイル名の文字に制限・注意事項があるため、UTF-8の処理検証と、さくら環境での保存・取得・直接URLアクセスの確認を分けて記録します。
