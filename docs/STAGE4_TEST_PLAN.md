# 段階4 試験条件

対象：`php85-support`、PHP 8.3.36／8.5.12、Linuxコンテナ、ローカルChrome。段階4の実装変更に伴う回帰・追加試験。実機FreeBSD、公開サイト、外部エディター本体を対象外とする範囲。

## 入力と観測

通常のHTTPフォーム／AJAX、multipartアップロード、ダウンロード、ChromeのDOM操作による入力。認証済みセッションやDB行の直接注入を行わない条件。テスト用の設定・初期ファイルはDockerイメージ構築時の固定fixture。ファイルツリー・PHPログ・ソースハッシュの読取り観測。

段階3からの仕様変更：ログインを含むPOSTへの画面発行CSRFトークン追加、ログアウトのPOST化。段階3の元ケース・元証跡を維持し、旧HTTP入力のままのPASSへの読み替えを禁止する扱い。基本操作のファイル内容・権限・境界値の期待結果は段階3と同一。新ケースIDでの再検証。

全ケース共通：対象ソースとコンテナのハッシュ一致、PHPの警告・非推奨・致命的エラーなし。アプリによる期待結果との不一致はFAIL、試験環境により入力や観測へ到達不能の場合のみBLOCKED、未実行はNOT RUN。

ZIP展開先：同名の新規ディレクトリ（`sample.zip` → `sample/`）。既存ディレクトリ・ファイルへの上書きなし。上限：1,000エントリー、合計非圧縮容量MAXSIZE（MAXSIZE無制限時20MB）、LIMIT併用。ZIP拡張の有無を実行証跡へ記録する条件。
