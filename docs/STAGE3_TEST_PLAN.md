# 段階3・互換性修正の回帰試験

要求：移行計画の段階3「本体と基本操作の互換性修正、必要な回帰テスト」。PHP 8.3.36／8.5.12の両方でのHTTP操作と結果の一致、対象経路のPHP診断通知なし。

## 条件

- 対象：修正済み本体、標準構成のsearch／edit、ユーザー・グループ設定。原本基準`a7511ad`、修正前証跡は段階2のまま保存
- 環境：段階2の固定Dockerイメージ、`E_ALL`、localhost公開、`dev/config.test.php`と`dev/seed.php`。各試行前のコンテナ再構築・再作成
- 追加設定：viewer／readers＝ルート`files/nested`、作成・転送・ファイル操作無効、search無効、editをtrue指定。ungrouped＝グループ指定なしの追加ユーザー
- 操作経路：HTTP GET、フォームPOST、multipartアップロード、既存AJAX用POST。実際のアプリとセッションCookieの使用。ファイル・セッション・DBへの直接書込みや模擬応答なし
- 観測：HTTPコード、HTMLのフォーム・リンク・入力値、ダウンロード内容のバイト一致とSHA-256、サーバーログ。再帰検索・書込み拒否等も外部応答とデータ保全による確認
- 判定：必須期待結果の不一致またはPHPエラー・警告・非推奨通知はFAIL、外部環境により操作不能はBLOCKED、証跡不足はINCONCLUSIVE、後続未到達はNOT RUN。失敗を残した上で修正後に同条件で再実行
- 範囲外：ブラウザー描画・JavaScript操作、認証方式刷新、全プラグインの完成、ZIP／URL取得／chmod／symlinkの操作、FreeBSD実機の受入
