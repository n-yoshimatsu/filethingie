# 段階6 Basic認証だけの移行リハーサル

SA-604で受領した表示差分を引き継ぐ、別URLの複製環境。既存アプリの切替・既存データへの上書きなし。段階5の固定ソースに、任意のpresentation設定・CSS色変数・メニュー表示条件だけを追加した配布。設定なしの場合は従来表示の継続。

## 配置

```text
php sakura-rehearsal.php BACKUP_DIRECTORY HOME_DIRECTORY WEB_ROOT HTTPS_APPLICATION_BASE_URL
```

完了済み保全コピーの全内容・権限・更新時刻の照合後、files配下を実コピー。ハードリンク・本番データへの参照なし。既存configの静的な設定候補を確認し、コピーした設定へ表示値と非公開PHPログの設定を追加。旧アプリ・旧config・users.shのセットアップ中の実行なし。Webアクセス時は更新版アプリとコピーしたconfigの実行。

タイトル・見出し・案内文のサーバー内抽出、文字列の公開リポジトリへの保存なし。配色・3箇所の幅・favicon・フッター・メニュー表示の引継ぎ。「同じファイル名の登録は、上書きしません。」への案内修正。日本語対応済みのファイル名検査と同名拒否の維持。メニュー非表示は権限の追加・削除ではない扱い。

公開先は既存アプリ直下の新規ft-stage6-rehearsal-*のみ。非公開設定・ログ・記録はホーム直下の新規.ft-stage6-rehearsal-*、親0700・ファイル0600。公開領域外で全組立てとハッシュ照合後にディレクトリ移動。コピーの容量分と資材用の空きが必要。アカウント残容量の取得なし、書込みエラー時は未完了。

既存の.htaccessのBasic認証・realm・AuthUserFile・Require valid-userの継続。認証ファイルの変更・新規アプリパスワードの作成なし。対応外ディレクティブ、動的設定、追加ユーザー・グループ、未対応プラグイン、保存先内の.htaccess等は公開前の停止対象。上位認証の未解決参照は棚卸し記録を保持、全Apache設定の実効確認とは別の扱い。

コピーされたfiles内に追加する.htaccessで、ディレクトリ一覧・実行形式・ドットファイルの直接取得を拒否。設定等も直接取得を拒否。追加.htaccessの一覧・操作対象からの除外。既存のphpinfo.php・php.ini~・users.sh・認証ファイルを公開先へコピーしない構成。favicon・ライセンス・現行プラグイン資材・複製データの配備。

PREPAREDは配置と内容照合の完了。HTTPのBasic認証、画面表示、ファイル操作の合格とは別の状態。既存利用者のBasic認証でPreview URLへアクセス、File Thingieの追加ログインなし。検証対象は複製なので、本番と同じファイルを編集しても既存ファイルへの反映なし。検証用ファイルは識別可能な専用名で作成する方針。

## 検証範囲

TS-608／609：PHP 8.3／8.5の人工保全コピーからの配置、内容・権限・更新時刻、表示値・設定非実行、原本不変、未対応認証と改変コピーの拒否。

TS-610／611：同キットを用いるLinux Apache＋Chrome、未認証401（アプリ・直接ファイル・CSS）、Basicだけの一覧、配色・幅・文言・メニュー、実ファイル選択からの日本語／空ファイル転送とハッシュ、同名拒否・元内容維持、フォルダー作成・名前変更・移動・編集・検索・削除、CSRF拒否、PHPログの確認。さくらのcgi-fcgi経路の代用とはしない範囲。

SA-605：さくらの保全コピーを入力とする配置・照合結果。SA-606：実機のBasic認証だけの画面・操作確認。現段階で未実施の状態。
