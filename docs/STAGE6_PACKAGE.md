# PHP 8.3／8.5配布候補

状態：段階5合格ソースの配布候補、本番移行と正式リリースは未完了。

アプリ固定元：`3ab04adb323c1f5fe2d8b1cd144b6cbb3d0a1eb4`。
`app/index.php`は固定元`ft2.php`のバイト単位の複製。PHP 8.3.36／8.5.12でのアプリ検証、さくらPHP 8.3.36／cgi-fcgiでの分離配置受入済み。PHP 8.5のさくら実機検証は対象外。

## 配布内容

- `app/`：本体・同梱プラグイン・翻訳・CSS／JS・設定サンプル・本体とjQueryのライセンス。
- `manifest.json`：アプリ固定コミット、ファイル一覧、SHA-256。
- `DEPENDENCIES.md`：依存・許諾・無効化済み機能の説明。
- `config.php`、Basic認証ファイル、管理対象ファイル、検証用アカウント、受入入力、開発環境の同梱なし。

## 新規導入

1. PHP 8.3または8.5、HTTPS、session／jsonの確認。db／logはPDO SQLite、zipはZipArchive、URL取得はcURLの任意依存。
2. ZIPをローカルまたは非公開作業領域へ展開し、SHA-256とmanifestの照合。
3. 新規の公開先へ`app/`の内容を配置。保存先ディレクトリの作成、`config.sample.php`を基にした`config.php`の作成。サンプルのDIR「.」を本番向けの専用保存先へ変更。
4. アプリ内ログイン利用時はUSERNAMEとPASSWORD_HASHの設定。ハッシュ生成用ツールはリポジトリの`tools/hash-password.php`。Basic認証だけの利用時はWebサーバーによる認証を先に設定し、LOGIN=falseの設定。Basic認証なしでLOGIN=falseを公開する構成の対象外。
5. 配置先に合うファイル・ディレクトリ権限と非公開PHPログの設定、未認証アクセス拒否と通常操作の確認。db／log使用時は公開ルート・管理DIRの外にDBを配置。

## 既存環境の更新

既存フォルダーへのZIP全体の上書き展開は禁止。先に設定・認証関連・保存データ・独自変更を棚卸しし、保全コピーと書込み停止中の最終バックアップ、隔離したリハーサルと復元確認を実施。

今回のさくら移行ではLOGIN=false、既存のBasic認証、保存先の相対配置と直接URL、50 MiB上限、英語UI、編集・検索の設定を維持。既存config.phpをサンプルへ置換する操作なし。users.sh、users.txt、.htaccess、認証ファイルの自動実行・削除・上書きなし。

アプリの更新対象はmanifestにある配布ファイル。独自変更との差分確認後に更新対象を確定。廃止された旧JS・プラグインの片付けはバックアップと参照確認後の個別操作。URL取得は許可ホスト設定がなければ無効、旧remember meは廃止、config／fileinfo／旧外部エディター連携は無効。

移行手順と確認状況はリポジトリの`docs/STAGE6_MIGRATION.md`、設定互換性は`docs/STAGE4_MIGRATION.md`を参照。現時点でこのZIPを本番へ配置する段階ではない状態。

## 復元

保全コピー用キットの復元機能は、新規の非公開ディレクトリへの復元と照合専用。本番を元に戻す機能の同梱なし。本番での切戻しは停止中の対象ファイル・権限・データ差分を確定した個別手順。

旧アプリはPHP 8.3で不動作との報告あり。旧ソースの復元によるサービス回復の保証なし。PHP 5.6への自動切替なし。
