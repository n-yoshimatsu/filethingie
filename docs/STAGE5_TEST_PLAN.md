# 段階5 試験条件

段階5のCI・総合試験・FreeBSD受入整備に伴う追加シナリオ。段階4の合格条件・証跡の保持。新規ケースの設計であり、利用者による個別シナリオ承認済みとの扱いなし。

## 共通条件

- PHP 8.3.36／8.5.12、digest固定のLinux Apacheコンテナ、公開済みダミー資格情報、使い捨てファイル・SQLiteデータの使用。
- HTTPフォームでのログイン・取得したCSRFトークンによる操作。セッションファイル・DB内部値の注入なし。
- 機能不一致のFAIL、環境により入力・観測に到達不能の場合のBLOCKED、未実施のNOT RUN。確定したFAILの保持、残り手順の未実施範囲の記録。
- 各ケース直前のID・名称表示。実入力、HTTP結果、比較結果、ソース・ハーネスハッシュ、PHP診断ログの保存。
- 通常回帰は段階4と同じ順序・入力・期待結果。再実行前のコンテナ初期化。Firefoxは独立した新規ケースとして同一UI操作・比較内容の適用。

## 範囲外・追加確認

Safari／実機Firefox・Chromeとの差、FreeBSDでの負荷・全ファイル操作の同時更新、既存本番config／SQLiteの移行、実データの大容量運用の未検証。URLのリダイレクト禁止・DNS固定の実装確認と、悪意ある外部DNSを用いた実ネットワーク試験の区別。短時間試験・単体時計モデルを実時間セッション期限の合格へ代用しない扱い。
