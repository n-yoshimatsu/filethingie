## 判定と失敗時の扱い

- PASS：必須条件・操作・観測の完了と期待結果の一致
- FAIL：構文エラー、診断通知、HTTP 500、フォーム欠落などの不一致。アプリ自身の起動失敗もFAIL
- BLOCKED：コンテナ未起動、接続不能、ソース不一致などによる操作・観測への未到達
- INCONCLUSIVE：外部応答の取得後、必須のログ収集失敗などによる証拠不足
- NOT RUN：未実施ケース。段階2の対象外の基本操作・ブラウザー・FreeBSD確認についても未実施の明示
- 不具合発見時：元ソースと証跡の保持、無断修正・模擬応答・入力経路の代替なし。原因と後続の未評価範囲の分離
- 構文確認の終了コード0：構文だけの結果。プラグインの実行互換性・機能合格を意味しない記録
